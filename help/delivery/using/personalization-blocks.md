<trans-unit id="tu6" xml:space="preserve">
<source xml:lang="en-US">Personalization blocks are dynamic, personalized and contain a specific rendering that you can insert into your deliveries. For example, you can add a logo, a greeting message, or a link to a mirror page. See <ph id="1" ctype="x-LINK">[</ph>Insert personalization blocks<ph id="2" ctype="x-LINK">](#inserting-personalization-blocks)</ph>.</source>
<target xml:lang="en-XX">Les blocs de personnalisation sont dynamiques, personnalisés et contiennent un rendu spécifique que vous pouvez insérer dans vos diffusions. Vous pouvez par exemple ajouter un logo, un message de salutations ou un lien vers une page miroir. Consultez la section <ph id="1" ctype="x-LINK">[</ph>Insertion de blocs de personnalisation<ph id="2" ctype="x-LINK">](#inserting-personalization-blocks)</ph>.</target>
</trans-unit>
